Plan detail / Basic

Basic: Full Plan Guide.

$2 monthly or $10 yearly. Basic includes heavy ads, three explicitly listed learning sites, and no PRRP use access.

01 / OVERVIEW

Included education sites

The current Basic listing names Canvas, NoRedInk, and GMetrix. Other supported-site availability should be checked against the matrix instead of assumed.

02 / DETAILS

Advertising and PRRP

Basic has heavy ads. It does not include PRRP usage access, which is separate from the residential hosting default.

03 / DECISION

Hosting default

Residential hosting is enabled by default. Basic does not include a control to turn hosting off; only Pro has that setting.
