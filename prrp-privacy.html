PRRP / network transparency

PRRP & Network Transparency.

A readable overview of the network terms that should be visible before a person chooses to use PRRP.

01 / OVERVIEW

Explain the route

PRRP is a residential proxy relay. Product information should make clear when traffic is routed through the relay, what traffic category is involved, and which limits apply.

02 / DETAILS

Hosting default

Residential hosting starts enabled by default on all plans. Only Pro offers a control to switch hosting off. This setting is separate from the customer’s own PRRP usage allowance.

03 / NEXT STEP

Make an informed plan choice

Review the stated behavior, caps, and controls before choosing a tier. Do not treat proxy routing as a promise of anonymity or as a way to bypass a school’s rules.
