Network guide / PRRP

Pavio Residential Proxy Relay.

Understand PRRP usage allowances, residential hosting defaults, and the controls available on each plan.

Hosting is on by default

Residential hosting is enabled by default on Basic, Standard, Core, and Pro. Only Pro includes a setting to turn hosting off. This is separate from using PRRP for your own browsing.

01 / USING PRRP

Your usage allowance

These weekly and monthly limits describe PRRP use for your own browsing. Basic has no use access. The two caps apply independently; no daily cap is specified.

02 / HOSTING

Connection participation

Residential hosting lets the connection participate in the relay network. It is enabled by default on all plans. Only Pro can disable hosting.

03 / MAKE A CLEAR CHOICE

Read the plan carefully

Review the default, limits, and control availability before purchase. Proxy routing is not a promise of anonymity and should not be used to bypass school or service rules.
